# Security

This plugin is part of [Portway](https://github.com/rath/portway). It bundles
only the `setup` and `doctor` skills: no MCP server, startup hook, model
credentials, or platform binary.

## Reporting a vulnerability

Report vulnerabilities privately through GitHub: open the
[repository's Security tab](https://github.com/rath/portway/security) and
choose **Report a vulnerability**. Do not open a public issue for a suspected
vulnerability.

Portway is pre-1.0. Fixes land on `main` and in the next release; older
releases are not patched. The full policy, including what Portway is trusted
with, is in the repository's
[SECURITY.md](https://github.com/rath/portway/blob/main/SECURITY.md).
